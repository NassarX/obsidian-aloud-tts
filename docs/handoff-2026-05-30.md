## Key Technical Context

Chatterbox outputs IEEE Float WAV (format 3). Aloud's `parseWavHeader` in `audioProcessing.ts` asserts `format === 1` (PCM only). Fix: accept formats 1 and 3, with Float32→Int16 conversion before lamejs MP3 encoding.

The OpenAI-compat call body in `openai.ts → openAICompatCallTextToSpeech` needs three extra fields for Chatterbox: `exaggeration`, `cfg_weight`, `temperature`.

Aloud monorepo structure:
- `packages/open-tts/` — TTS model adapters, settings, player logic (no Obsidian imports)
- `packages/obsidian/` — Obsidian plugin wrapper
- `packages/ui/` — React settings UI

New Chatterbox provider → `packages/open-tts/src/models/chatterbox.ts`
BatchPlayer → `packages/open-tts/src/player/BatchPlayer.ts`

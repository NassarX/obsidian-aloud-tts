## What Was Built (This Session)

### New Providers
- **Chatterbox** — local voice-clone TTS via self-hosted HTTP server (`localhost:4123`). Settings: apiBase, voice, exaggeration (0.45), cfgWeight (0.65), temperature (1.0), batchMode, audioFolder. Health-check notice fires on plugin load if server is offline.
- **XTTS was evaluated and removed** — Chatterbox benchmarked 7.5s/sentence vs same for XTTS, with better quality. Not shipped.

### Batch Vault Caching
- `BatchPlayer` — sequential sentence generation with abort-signal support, progress/complete/error callbacks.
- `PermanentCache` — SHA-256 keyed provider-agnostic cache interface.
- `VaultWriter` — Obsidian vault adapter: saves MP3s to `_audio/`, embeds a `> [!abstract]+` collapsible callout after frontmatter with provider · voice · date · note title.
- Fish Audio, MiniMax, Chatterbox all support batch mode (configurable per-provider).
- **Bug fixed (2026-06-03):** After fresh generation, `player.startPlayer` was never called → audio was saved but never played. Fixed + errors now surface as Notices.

### Audio Toggle + Doc-Switch
- Clicking play on the active note now **toggles** play/pause (was: always restart).
- `forceRestart` flag bypasses toggle (used by context-menu action and auto-play).
- `isDetachedAudio` flag: when audio plays in background after a doc switch, the toolbar floats to the focused editor. Cleared when fresh session starts.
- **Doc-switch behavior** setting (stop / continue / auto-play) — controls what happens when user opens a different note while audio plays.

### Provider Fixes
- **Fish Audio:** switched all requests to `requestUrl()` (Obsidian's CORS-safe HTTP) — fixes desktop CORS errors. 401/403 error messages improved.
- **Gemini:** `GeminiRateLimiter` — module-level serializer that queues concurrent chunk requests and enforces 32s cooldown after any 429. Prevents the retry storm on the free tier.
- **ChunkLoader:** 429 errors now use 30s base backoff (capped at 2 retries). Other errors keep 250ms exponential backoff.
- **MiniMax:** batch mode + audio folder added. China endpoint support confirmed.
- **Hume/Inworld/Polly:** minor cleanup — unused imports, clearer error messages.

### Markdown Cleanup
- Readwise Tags lines and View Highlight links stripped before TTS.
- Fenced code blocks removed entirely (not just the fence markers).
- `[[wiki links]]` and `[[link|alias]]` resolved to readable text.
- Obsidian inline tags (`#tag`) de-hashed, callout markers (`> [!NOTE]`) stripped.
- Bare URLs simplified to domain only (`https://github.com/x/y` → `github.com`).
- `frontmatterLength()` exported — `ActiveAudioText` uses it to skip YAML when splitting sentences, while preserving correct document offset positions.

### WAV Float32 Support
- `parseWavHeader` now accepts format 3 (IEEE 32-bit float, used by Chatterbox).
- `wavBufferToMp3Buffer` converts float32 samples → int16 before MP3 encoding.

### PlayerView Improvements
- `TrackProgress` component: shows "N / Total" sentence counter + 50-char snippet.
- Play button hidden when a track is active (transport controls take over).
- Tooltip text shortened ("Autoscroll on/off", "Previous/Next sentence").
- Paused state shows ⏸ icon in progress display.

### Error Notices
- MobX reaction in `TTSPlugin` surfaces TTS errors as Obsidian Notices (debounced 1/5s).
- `formatTTSError` formats 429, 401, 403, 404, 5xx distinctly.

### Infrastructure
- **vitest** 3 → 4.1.8 (CVE fix).
- **Node** 20 → 22.22.3 LTS (pnpm v9 now works; was crashing on `node:sqlite`).
- **Pre-commit hook** restored to `pnpm run typecheck` after Node upgrade.
- 17 new tests added (BatchPlayer, PermanentCache, VaultWriter, ObsidianBridge behavior, TTSPluginSettings migration).

## Known Behaviors (Not Bugs)

1. **Batch hashes from cursor position** — play from cursor to end-of-doc is by design (matches streaming). If cursor is mid-doc, the cached vault file is a partial note. Force `from = {line:0, ch:0}` in the batch path if full-doc caching is always desired.

2. **Chatterbox server must be running** — health check fires a persistent Notice on load if offline. Server: `cd ~/Code/voice-reader/chatterbox-tts-api && uv run main.py`

3. **`epfLLM_meditron.md` has old-style callout title** — `🎙 fish · s1 · 3e433fe...` (UUID, no note title). Pre-dates the `noteTitle` field in `VaultWriter`. Won't auto-fix; harmless.
